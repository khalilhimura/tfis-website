Interactive

SSA-CMM Self-Assessment

5-question wizard on the home page scores AI maturity from L0 (Task Operator) to L5 (Sovereign Architect). Fully client-side — localStorage persists results for 30 days. Redirects to Thinkific course or whitepaper based on level.

Content

Content Architecture

Two Astro content collections with Zod schema validation. Philosophers (50 entries) drive an index with inline search filter plus per-slug detail routes. Writing collection supports tags, reverse-chronological listing, and RSS feed generation.

Build

Build & Deploy Pipeline

Astro 7 with output: 'static' and format: 'file' produces .html extensions. @astrojs/rss generates the Atom feed. Output deploys to Cloudflare Pages (or any static host). Node 22+ required. Site domain: thefutureissolo.com.

Design

Design System

Self-hosted Atkinson Hyperlegible (body) + JetBrains Mono (code/ui). CSS custom properties for all tokens. Dark/light mode respects prefers-color-scheme, persists to localStorage, toggles via button. Accent #c8511e, 720px reading container.

Philosophy

TFIS Philosophical Stack

Five Pillars: Agency, Clarity, Competence, Accountability, Security. Three OS components: TaskVal (cognitive ROI scoring), SovMem (durable memory vault), obra/superpowers (shipping discipline). Vision: one-person enterprise by 2030.
