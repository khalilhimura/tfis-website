# TFIS P2 Round 1 — Analytics, 404, RSS Feed

> **For agentic workers:** Small independent tasks — implement inline without subagent orchestration.

**Goal:** Add Cloudflare Web Analytics, a branded 404 page, and an RSS/Atom feed.

**Architecture:** All changes are static files. No backend, no build step. Analytics is either a Cloudflare dashboard toggle or a single `<script>` tag.

**Spec:** `docs/superpowers/specs/2025-07-17-tfis-site-p2-design.md`

## Global Constraints
- No backend, no build step
- Zero new JS dependencies
- Existing URL structure preserved
- Consistent nav/footer on all pages
- RSS feed must be valid Atom XML

### Task 3: Cloudflare Web Analytics

**Files:**
- Modify: `index.html`

**Two approaches depending on setup:**

**Approach A (if site is on Cloudflare):** Enable Web Analytics from the Cloudflare dashboard — no code changes needed.

**Approach B (if site is not on Cloudflare):** Add the beacon script tag:

- [ ] **Step 1: Add Cloudflare Web Analytics beacon**

In `index.html`, add this before the closing `</head>` tag (after the last `<link>`):
```html
<script defer src='https://static.cloudflareinsights.com/beacon.min.js' data-cf-beacon='{"token": "YOUR_TOKEN"}'></script>
```

Replace `YOUR_TOKEN` with the actual token from the Cloudflare Web Analytics dashboard.

- [ ] **Step 2: Commit**

```bash
git add index.html && git commit -m "feat: add Cloudflare Web Analytics beacon to index.html"
```
