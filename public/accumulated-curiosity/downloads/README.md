# Accumulated Curiosity

Open accumulated-curiosity.md for the continuous manuscript, or choose a chapter under book/chapters. Keep the book folder beside the continuous manuscript so its relative links to chapters, appendices, artifacts, and diagrams work. The original chapter files use paths relative to their own folders.

Optional code examples have individual guides in book/artifacts. Their synthetic data does not represent real customers or model performance. No coding is required for the main book exercises.
