# Rationale — Synthetic Fixture

Role: explanatory. This file does not replace the current instruction selected through [learning-loop-v1](learning-loop-v1.md).

The [first source input](inputs.md#test-a) contains an exact Wednesday commitment, an agreed but unassigned action timed “soon,” and an undecided reminder proposed for Friday. An output must preserve both precision and uncertainty. Neither filling every gap nor erasing every exact date is faithful.

The [second source input](inputs.md#test-b) contains two incompatible deadlines for the same action and owner, with no supplied superseding relationship. Its shared action and owner can be represented; a single confirmed deadline cannot be selected from the given evidence.

These are synthetic checks of limited distinctions. They do not establish that every conflict will be detected or that the source statements themselves describe real events. The [charter](charter.md) defines the permitted task.
